## Featured Project

### FoodSave Smart
**Full-Stack Web Application | Academic Group Project**

FoodSave Smart is a web-based solution designed to reduce food waste by enabling users to reserve discounted surplus food while incorporating temperature-based food safety controls.

**Key Features**
- Automated expiry-based discounts
- User authentication and food reservations
- Inventory and stock management
- IoT temperature monitoring and safety alerts
- REST API integration
- Cloud-hosted application and database

**Technologies**

Python · Flask · JavaScript · HTML · CSS · MySQL · REST APIs · Git · GitHub · Render · Aiven

**My Role and Contributions**

Scrum Master | Backend Development | Technical Integration | Deployment Coordination

My contributions included implementing backend functionality, developing reservation and discount logic, supporting database and API integration, coordinating Agile Scrum activities and verifying the deployed application.

The integrated project recorded 76 passing automated tests across backend and frontend test suites.
