## Featured Projects

### 01 | FoodSave Smart

**Full-Stack Web Application | Collaborative Software Engineering Project**

FoodSave Smart is a web-based platform designed to reduce food waste through surplus-food reservations, automated expiry-based discounts, inventory management and temperature-aware safety controls.

The application integrates a responsive frontend, Python Flask REST APIs, a MySQL database and simulated IoT monitoring.

**Key Features**

- Dynamic food catalogue with expiry-based discounts.
- User authentication and role-based access control.
- Food reservations, cancellation and stock management.
- Automated pricing and product availability rules.
- Temperature monitoring and SAFE/HOLD safety restrictions.
- Cloud-hosted frontend, backend and database.
- Automated backend and frontend testing.

**Technology Stack**

Python · Flask · JavaScript · HTML5 · CSS3 · MySQL · REST APIs · JWT · Pytest · Git · GitHub · Render · Aiven

**My Role and Contributions**

Scrum Master | Backend Development | Technical Integration | Quality Assurance

My contributions included developing and testing backend functionality, implementing reservation and discount logic, supporting database integration, coordinating Agile Scrum activities and verifying application behaviour across the deployed services.

The integrated project recorded **76 passing automated tests**, comprising 46 backend and monitoring tests and 30 frontend and API contract tests.

The project was developed collaboratively by Team Green as part of the CPU4106 university group project.

[View Live Application](https://foodsave-smart-1.onrender.com/)

### 02 | LaurentiuTech

**Interactive E-Commerce Website | Individual Front-End Development Project**

LaurentiuTech is a responsive electronics e-commerce website developed independently using HTML5, CSS3 and vanilla JavaScript.

The project demonstrates the implementation of dynamic product interfaces, client-side application logic, interactive shopping workflows, accessibility improvements and responsive web design without relying on front-end frameworks.

**Key Features**

- Dynamic catalogue containing 18 technology products.
- Product search, filtering and sorting.
- Interactive product galleries and configurable variants.
- Shopping cart with quantity management and LocalStorage persistence.
- Wishlist and product comparison functionality.
- Simulated checkout with conditional payment fields.
- Six-language interface and multiple currency options.
- Light and dark interface themes.
- Contact, newsletter and support chatbot interfaces.
- Responsive layouts and accessibility improvements.

**Technology Stack**

HTML5 · CSS3 · JavaScript · LocalStorage · Responsive Web Design · Chrome DevTools · Google Lighthouse · Git · GitHub

**My Role and Contributions**

Individual Developer | Front-End Development | UI/UX Implementation | Accessibility Testing

I independently developed the website structure, implemented interactive JavaScript functionality, designed responsive layouts and documented accessibility improvements using Google Chrome Lighthouse.

The project includes before-and-after accessibility testing evidence demonstrating identified issues and subsequent refinements.
